# Hamilton Consulting Group website

This repository contains the editable files for the Hamilton Consulting Group website.

## Main files

- `index.html` — homepage
- `styles.css` — shared visual styling
- `script.js` — navigation and site interactions
- `resources.js` — shared resource information
- Page folders such as `about`, `events`, `recruiting`, and `quill` — individual website pages
- `assets` — logos and graphics
- `files` — downloadable PDFs

## Current live site

https://hamilton-consulting-group.c24gfmmjxs.chatgpt.site/

The GitHub repository is a management and handoff copy. Uploading or editing files on GitHub does not automatically update the current ChatGPT Sites deployment.
